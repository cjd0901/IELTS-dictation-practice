<h1 align="center">雅思听写练习</h1>

基于王陆雅思语料库的听写工具，支持词汇预习、逐行听写、批改、错词复习和学习记录。页面采用深色风格，数据保存在当前浏览器本地。

## 听写练习

- **分组练习**：按章节选择词汇，每组 20 个词，最后一组按实际剩余数量展示。支持上一组、下一组及指定分组。
- **逐行听写**：每行填写一个单词或短语，点击发音按钮播放当前词汇。
- **自动发音**：开启后，聚焦尚未批改的输入行时自动播放该词。
- **连续播放**：从当前行开始，依次播放本组词汇。无输入时，在当前发音结束后等待 2.5 秒切换下一行；当前行有输入时，等待停止输入满 2 秒，并确保当前发音播完后再切换。
- **乱序练习**：在尚未批改时打乱本组顺序，已填写的答案随对应词汇一起保留。
- **按需批改**：点击“批改”仅检查已填写且尚未批改的行，展示正确答案、音标、中文释义与对错结果。空白行不计入成绩或错词本，可补填后继续批改。
- **查看结果**：显示正确词数、错误词数和正确率，可切换“只看错词”与“查看全部”。已批改的答案保持只读。
- **重新练习**：可重新开始本组；整组批改完成后，可通过“重练错词”集中练习本组答错的词汇。

## 我的词库

词库为 **王陆雅思语料库**，收录第 **3、4、5、11 章**的词汇，共 5,873 个词汇、32 个小节。

| 章节 | 词汇内容 |
| --- | --- |
| 第 3 章 | 名词 |
| 第 4 章 | 形容词与副词 |
| 第 5 章 | 短语 |
| 第 11 章 | 综合词汇 |

- 每节卡片展示章节分类、词汇数量和分组数量。
- 点击卡片主体，进入该节第一组听写练习。
- 点击“预习”，在弹窗中查看该节全部词汇，包含英文、以斜杠包围的音标和中文释义。
- 每个预习词汇均可单独播放发音，沿用当前口音、语速和重复次数设置。
- 词表支持滚动查看；关闭预习弹窗时停止发音，保留原来的听写进度。

## 错词本

- 听写批改后自动收录答错的词汇，同一词条不会重复收录。
- 展示错词的英文、音标和中文释义，支持按英文或中文搜索及单词发音。
- 点击“专项听写”，选取当前错词本中最多 20 个词进行复习。
- 已收录的词汇在后续听写或复习中答对后，会自动从错词本移除。

## 学习记录

- 展示累计听写词数、练习次数和正确率统计。
- 保留最近 100 次有效批改记录，包含练习时间、章节或复习类型、正确词数和正确率。
- 点击记录查看详情，对照当时填写的答案、正确单词和中文释义。
- 同一组分多次批改时，每次新增的批改结果分别形成记录；重复点击批改不会重复生成记录。
- 支持将已保存的学习记录与当前错词本导出为 JSON 文件。

统计以当前保留的学习记录为准；重复练习按各次实际批改的词数累计。

## 偏好设置与今日目标

| 设置项 | 功能 |
| --- | --- |
| 今日小目标 | 自定义每日目标词数，默认为 20 词，支持输入正整数 |
| 发音口音 | 选择英式英语或美式英语 |
| 播放语速 | 选择 0.7×、0.8×、1.0× 或 1.2× |
| 每词重复次数 | 选择每个词播放 1、2 或 3 次 |
| 自动发音 | 控制聚焦未批改输入行时是否播放发音 |
| 测试发音 | 试听当前发音设置 |

侧栏根据今日已批改词数展示目标完成进度。目标词数在点击“完成设置”后保存，发音选项即时生效并保存。

## 本地保存与发音

- 当前听写内容、批改状态、偏好设置、错词本及学习记录自动保存在当前浏览器，刷新或重新打开相同地址后可恢复。
- 无需账号，不提供跨浏览器、跨设备的数据同步。清除网站数据会清除本地学习记录。
- 记录导出包含学习记录和错词本，页面暂未提供导入恢复功能。
- 发音优先使用设备可用的英语语音；没有可用语音或播放失败时，尝试使用在线词典发音。在线发音需要网络，实际音色取决于设备与浏览器。
