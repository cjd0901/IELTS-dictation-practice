## 功能与兼容性清单

- 四个视图通过本地状态切换，无 URL 路由、后端、数据库或登录接口。
- 5,873 个词、32 个小节，词条 ID 为 `章节:原始索引`；每组 20 词，末组可不足 20。
- Enter 下一行；上下键切行；Shift + Enter 重播；Ctrl/Command + Enter 批改；输入法组合输入不触发快捷键；弹窗和历史详情打开时停用全局快捷键。
- 仅批改新填写且未批改的行；空白不计分。已批改行只读；重复提交不重复计入历史。批改后显示答案、音标、翻译，可只看错词。

- 原样保留大小写、撇号、连字符、连续空格、尾部句号/问号/感叹号归一化，以及 `=`、`／`、`/` 分隔的可接受答案。
- 浏览器英语语音：匹配口音且本地优先，其次匹配口音、任意英语；不可用/失败时回退有道 GET 发音接口。保留 URL 参数 `audio` 和 `type=1/2`、语速、重复次数、错误提示。
- 连播从当前行开始，每词结束后等待 2.5 秒；播放、停止、切页面/分组、重播和组件卸载时清理资源。
- 历史最多 100 次；保留部分提交单独形成记录的行为。日期、累计词数、平均正确率、当日计数、JSON 导出字段/顺序/文件名保持一致。

## 审查发现

- `App.tsx` 同时管理所有页面、浏览器资源与存储；大量单行 JSX 难以审阅，逻辑无独立测试入口。
- 每次按键会重复计算历史统计、词典答案并重建图标树；多个派生值、全局监听器依赖缺乏稳定边界。
- 发音失败回调、连播定时器、延迟聚焦和导出 URL 的生命周期需要集中管理与测试。
- 原有存储只有 JSON 解析保护，历史/错词数据深层形状未完整校验；本次不擅自引入可能改变兼容行为的数据清洗规则。
- 原有统计只覆盖保留的最近 100 次记录；跨午夜没有独立刷新定时器；这些是既有业务行为，不能以优化名义修改。
- 基线 `npm.cmd run build` 通过；`npm.cmd run lint` 0 错误、7 条 React 警告。现有项目无测试脚本。构建已有单个 JS 包超过 500 kB 的提示，主要包含完整词库。
- 本机 PowerShell 的 `npm.ps1` 入口异常；同一已安装 npm 的 `npm.cmd` 可正常执行。无需修改用户全局 npm 设置。

### 合并的重复逻辑与效率改善

- 抽出统一的答案判定、部分批改、错词更新、历史上限、旧记录迁移、统计和乱序逻辑，均有回归测试。
- 四个页面复用图标、弹窗和空状态，不引入 UI 框架。图标路径移至模块常量，减少输入时重复创建元素。
- 历史统计按历史与本地日期缓存；错词搜索按词表与查询缓存；单词行使用稳定回调和 `memo`，避免每个按键都重渲染其余单词行。
- 随机数在事件处理器中只生成一次，避免放进 React Strict Mode 可能重复调用的 state updater。
- 发音服务通过播放令牌屏蔽过期回调；停止/卸载时暂停音频、取消语音并解绑回调；连播、提示、延迟聚焦计时器清理集中处理。
- JSON 导出仍保留原来的 1 秒对象 URL 生命周期，避免关闭视图影响正在发起的下载。不擅自改成提前撤销 URL。
- 未引入运行时或测试框架依赖；`package-lock.json` 与原依赖声明完全不变。重构期间使用的临时格式化工具缓存已随备份目录清理。

### 保留的问题与人工回归

1. **6 条 lint 警告**：原有持久化成功/失败状态反馈、兼容迁移在 effect 中更新状态，以及按渲染获取本地日期。保留这些行为，避免为消除警告改变旧数据迁移、存储失败提示或跨午夜的刷新时机。
2. **构建包大小提示**：完整词库仍同步打包，JS 包略有模块拆分开销。未通过提高警告阈值掩盖，也未引入懒加载、额外加载状态或网络依赖来改变原体验。
3. **损坏存储的深层数据形状**：现有 JSON 解析保护及旧存档接受规则不变，未擅自清洗未知数据。更严格的结构校验应作为后续独立兼容性变更评审。
4. **真实声音**：需在用户实际 Chrome/Edge、不同操作系统英语音色、有道网络不可达、浏览器禁止发声时手动试听；自动测试验证了分支与资源状态，没有声称验证听感。
5. **连播实际间隔、输入法和辅助工具**：需人工确认真实音频结束后的 2.5 秒间隔、中文输入法组合输入及读屏操作。纯快捷键与播放逻辑已自动覆盖。
6. **全平台原生控件**：主要桌面/移动断点已与基线对照；Safari、Firefox、浏览器缩放及系统字体缺失情况下仍建议人工回归，尤其是原生下拉框。
7. **开发热更新**：拆分 Hook 边界期间，旧开发页面曾记录 Hook 顺序热更新提示；最终已触发完整 HTML 重载，并在全新生产页面验证没有运行时错误。历史热更新日志与最终构建运行状态已区分记录。
